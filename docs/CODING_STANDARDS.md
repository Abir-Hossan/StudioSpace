# Coding standards

- Keep feature state local and use existing TanStack Query cache keys.
- Keep reusable UI independent of feature pages and use typed props and accessible controls.
- Put HTTP parsing and response handling in controllers. Keep reusable transactions in services.
- Preserve status codes, middleware ordering, authorization filters and schema relationships.
- Preserve theme tokens and stylesheet order. Comment constraints and contracts that are hard to infer.
- Validate the affected workflow with existing checks. Add a regression case when existing coverage would miss the defect.
